### About Me

I am a software engineer dedicated to building high-performance, resilient, and bleeding-edge digital systems. My approach treats development as a discipline of precision, micro-optimization, and zero latency — turning standard web requirements into scalable, enterprise-grade ecosystems.

- 🌍 Based in Pekalongan, Central Java, Indonesia
- 🧠 Currently learning Python, Django, and more
- 👥 Open to collaborating on enterprise-level projects
- 💬 Ask me about architectural web design
- ✉️ Reach me at [nareswara353@gmail.com](mailto:nareswara353@gmail.com)

### Architectural Philosophy

- **Extreme Performance Execution** — turning standard web solutions into optimized, concurrent systems capable of intense data throughput
- **Bleeding-Edge Integration** — React 19 and Server Actions inside Next.js, paired with the type-safe backend power of .NET Core
- **Low-Level Capabilities** — critical frontend computations written in Rust and compiled to WebAssembly for native execution speed
- **Declarative Infrastructure** — infrastructure as code via Terraform, serverless caching via Upstash, edge security via Cloudflare

### Current Focus

Exploring the boundaries of decentralized finance protocols, real-world asset tokenization, and high-throughput blockchain mechanics using Rust.
